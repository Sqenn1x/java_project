Документация

Архитектура проекта

Проект построен на Spring Boot, JPA и MySQL, фронтенд на чистом JavaScript с REST API.

  • Задачи привязаны к пользователю по userId.
  • У каждого пользователя может быть несколько независимых Kanban-досок.
  • Kanban-доска с перетаскиванием карточек.
  • Типы и приоритеты задач, назначение владельцу доски, комментарии и вложения.
  • Backlog и спринты с сохранением задач в завершённом спринте.
  • Таймлайн со сроками начала и окончания задач.
  • ИИ-ассистент управляет задачами текстовыми командами.
